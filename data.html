The Pipeline

From Raw Data to the Page

No database and no server: scheduled jobs write JSON, and a commit deploys the site.
  1. 1. Public data

    Play-by-play, rosters, injuries and lines from nflverse. Expert rankings from FantasyPros. Forecasts from Open-Meteo and the National Weather Service.

  2. 2. Scheduled scans

    GitHub Actions re-scores every game and player six times a week, with extra game-day runs for Wind Watch forecasts.

  3. 3. Freeze

    Each pick, ranking and wind spot locks by its own game and never changes, so nothing can be graded with hindsight.

  4. 4. Grade

    Every frozen number is scored against the final result and set beside Vegas or FantasyPros, on the same games.

  5. 5. Publish

    The scan commits JSON to GitHub, which redeploys a static site on Render. Pages just read those files.

The feedback loop

New ideas don't go straight into a model. Separate test scripts run each one against past seasons it wasn't fit on, and only what holds up there moves into the scans.

Method

How to Read This Page

The terms

EPA (expected points added) measures how much each play changed a team's scoring chances. Correlation runs from 0 (no relationship) to 1 (perfect). Against the spread asks whether a team beat Vegas's handicap, and 52.4% right is the break-even point at standard odds. A 95% range is where the true effect plausibly sits, given how noisy the sample is.

Out of sample

A model always looks good on the data it was fit to, so the numbers here come from games it never saw. Game constants are fit on 2021–2024 and scored on 2025 and 2026. The other tests hold out one season at a time, fit on the rest, and predict the one left out. Where a test's ideas came from seeing those same seasons, the note says so.

The code

All of it is public: the game model, fantasy scan, and the wind, team, streaming, factor, rating, fantasy and edge labs.

Educational research project, not betting or financial advice. Everything here is one tunable model's output and a set of backtests, not a guarantee of results.
